# Manajemen Bandwidth Menggunakan Stochastic Fairness Queuing (SFQ)

Proyek ini membahas penerapan manajemen bandwidth menggunakan algoritma Stochastic Fairness Queuing (SFQ) pada router MikroTik RB941 untuk mengatasi ketimpangan distribusi bandwidth antar pengguna jaringan. Infrastruktur jaringan menggunakan konfigurasi Bridge yang terintegrasi dengan DHCP Server dan Network Address Translation (NAT) untuk mendistribusikan alamat IP secara otomatis serta menyediakan akses internet bersama. SFQ diterapkan untuk mengatur distribusi bandwidth secara lebih merata pada setiap aliran data sehingga dapat mengurangi dominasi penggunaan bandwidth oleh pengguna tertentu dan menjaga kestabilan jaringan.

## Ruang Lingkup Implementasi

- Perancangan topologi jaringan menggunakan MikroTik RB941.
- Konfigurasi Bridge Interface.
- Konfigurasi DHCP Server untuk distribusi alamat IP otomatis.
- Konfigurasi NAT untuk akses internet bersama.
- Penerapan algoritma Stochastic Fairness Queuing (SFQ).
- Pengujian konektivitas dan distribusi bandwidth jaringan.

## Perangkat dan Perangkat Lunak

- MikroTik RB941-2nD
- MikroTik RouterOS
- WinBox
- Laptop/PC
- Kabel Ethernet
- Koneksi internet
