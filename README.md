# MikroTik Network Projects

Repositori ini berisi dokumentasi proyek dan praktik konfigurasi jaringan komputer menggunakan perangkat MikroTik RB941 selama masa perkuliahan di Program Studi Sistem Komputer, Universitas Sriwijaya. Materi yang didokumentasikan mencakup implementasi layanan jaringan, pengelolaan alamat IP, konfigurasi Network Address Translation (NAT), serta pengujian konektivitas antarperangkat. Setiap proyek dilengkapi dengan laporan yang menjelaskan tujuan, perancangan topologi, tahapan konfigurasi, dan hasil pengujian sebagai dokumentasi penerapan konsep jaringan komputer secara praktis.

## Project Documentation

### 1. DHCP Server on Bridge Network
Implementasi DHCP Server pada infrastruktur jaringan berbasis Bridge untuk mendistribusikan alamat IP secara otomatis kepada perangkat yang terhubung.

Folder: `dhcp-server-bridge/`

### 2. Masquerade PAT Configuration
Implementasi Masquerade Port Address Translation (PAT) pada MikroTik RB941 untuk memungkinkan beberapa perangkat dalam jaringan lokal mengakses internet menggunakan satu alamat IP publik.

Folder: `masquerade-pat/`
