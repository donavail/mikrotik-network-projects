# Masquerade PAT Configuration

Dokumentasi proyek implementasi Masquerade Port Address Translation (PAT) menggunakan router MikroTik RB941. Proyek ini berfokus pada konfigurasi NAT untuk memungkinkan beberapa perangkat dalam jaringan lokal berbagi satu alamat IP publik yang diperoleh secara dinamis melalui koneksi internet. Implementasi dilakukan melalui konfigurasi antarmuka jaringan, pengaturan NAT, dan pengujian konektivitas untuk memastikan perangkat dapat mengakses jaringan eksternal.

## Implementation Scope

- Perancangan topologi jaringan.
- Konfigurasi koneksi wireless pada MikroTik RB941.
- Pengaturan interface dan IP Address pada perangkat klien.
- Konfigurasi NAT Masquerade.
- Implementasi Port Address Translation (PAT).
- Pengujian konektivitas jaringan menggunakan beberapa perangkat.

## Tools and Devices

- MikroTik RB941
- MikroTik RouterOS
- WinBox
- Laptop/PC
- Ethernet Cable
- Wireless Network
