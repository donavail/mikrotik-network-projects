# DHCP Server on Bridge Network

Dokumentasi proyek implementasi DHCP Server pada infrastruktur jaringan berbasis Bridge menggunakan router MikroTik RB941. Proyek ini bertujuan untuk menerapkan pendistribusian alamat IP secara otomatis kepada perangkat yang terhubung dalam jaringan lokal, sehingga mengurangi kebutuhan konfigurasi IP secara manual dan mempermudah pengelolaan jaringan.

## Implementation Scope

- Konfigurasi Bridge Interface pada MikroTik RB941.
- Implementasi DHCP Server untuk pendistribusian alamat IP otomatis.
- Pengaturan IP Pool dan Lease Time.
- Konfigurasi parameter jaringan seperti Gateway dan DNS.
- Perancangan topologi jaringan.
- Pengujian konektivitas antarperangkat.

## Tools and Devices

- MikroTik RB941
- MikroTik RouterOS
- WinBox
- Laptop/PC
- Ethernet Cable
